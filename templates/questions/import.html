CSV 格式說明
欄位名稱 必填 說明 範例
title 必填 題目標題 下列哪個是迴圈？
content 必填 題目內容（可多行） 在 Python 中…
option_a 必填 選項 A for
option_b 必填 選項 B loop
option_c 必填 選項 C repeat
option_d 必填 選項 D iterate
option_e 選填 選項 E（如「以上皆非」）
留空則不顯示第五選項		 以上皆非
correct_answer 必填 正確答案（A/B/C/D/E） A
category 選填 分類名稱（不存在則建立） 基礎語法
difficulty 選填 難度：easy / medium / hard
預設 medium		 easy
year 選填 年份（整數） 2023
hint 選填 第一層提示 想想迴圈關鍵字
solution_idea 選填 解題思路 回想基本語法…
explanation 選填 完整詳解 Python 使用 for…
tags 選填 標籤，逗號分隔（不存在則建立） Python,迴圈,基礎
is_active 選填 啟用狀態，預設 True True
